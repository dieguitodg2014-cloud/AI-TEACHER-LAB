# Pedagogical Framework

AI TEACHER LAB uses a communicative, learner-centered approach supported by Backward Design.

## 1. Backward Design

Instruction begins with the desired learning outcome and evidence of learning, then determines the experiences needed to reach that outcome.

**Outcome -> Evidence -> Learning experience -> Practice -> Reflection/revision**

## 2. Communicative orientation

Language is taught as a tool for meaningful communication, not only as an object of grammatical study. Activities should create a reason to understand, say, read, write, or listen to language.

## 3. Progression

Where appropriate, instruction moves from:

**Model/input -> controlled practice -> guided practice -> communicative practice -> freer production**

The sequence is flexible. It must serve the learning objective rather than become a mechanical template.

## 4. Scaffolding

Support should be sufficient for successful performance and reduced as learner independence increases.

## 5. Meaning before mechanical repetition

Controlled practice has a purpose: accuracy, noticing, confidence, or preparation for communication. It should not dominate the lesson when the goal is communicative use.

## 6. Interaction

Pair work, small-group work, teacher-learner interaction, information gaps, role plays, problem solving, and other interaction patterns should be selected according to the objective and level.

## 7. Accuracy and fluency

AI TEACHER LAB recognizes both accuracy and fluency as important, but their relative emphasis depends on the lesson objective, learner level, and stage of practice.

## 8. Context

Target language should normally appear in a meaningful context before learners are asked to use it independently.

## 9. Differentiation

Differences in learner readiness should be addressed through task support, grouping, challenge, modeling, and output expectations rather than by simply adding more work.
