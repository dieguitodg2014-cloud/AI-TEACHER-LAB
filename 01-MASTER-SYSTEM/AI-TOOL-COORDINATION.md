# AI Tool Coordination

AI TEACHER LAB may use multiple AI tools, but pedagogical responsibility remains centralized in the system's Pedagogical Director.

## Primary role of ChatGPT

- Interpret instructional goals.
- Design pedagogical solutions.
- Apply level control.
- Review language and pedagogy.
- Coordinate other tools.
- Perform final quality control.

## Specialized production tools

Other tools may be used for specialized production, transformation, visualization, audio, presentation, research, or backup tasks when they add clear value.

Tool selection must follow pedagogical purpose rather than tool availability or novelty.

## NotebookLM First Principle

NotebookLM is the preferred primary production tool for classroom audiovisual and multimodal resources when its available capabilities match the requested pedagogical purpose.

This includes, when supported by the current NotebookLM workflow:

- classroom presentations and slide-based visual explanations;
- audio materials and model conversations;
- video or audiovisual learning resources;
- study materials and source-based learning resources;
- multimodal transformations of approved classroom content.

NotebookLM has production priority for these purposes because the system is designed to transform an approved pedagogical source into coherent multimodal classroom resources.

This is a priority rule, not an absolute requirement. Another tool may be selected when NotebookLM cannot provide the required format, when a specialized production need is better served elsewhere, or when the teacher explicitly chooses another tool.

## NotebookLM source-control workflow

NotebookLM should receive an approved pedagogical source rather than an unvalidated teacher request whenever the resource is being produced as part of an AI TEACHER LAB classroom package.

The approved source must preserve:

- learning objectives;
- target level;
- communicative purpose;
- target language;
- assessment purpose;
- sequence and instructional intent;
- relevant constraints and classroom requirements.

NotebookLM may transform, visualize, narrate, or present the approved content, but it must not silently redefine the pedagogical intent.

## Canva's role

Canva remains a specialized visual-production tool. It may be used for:

- presentation designs requiring specific visual control;
- posters and infographics;
- flashcards and classroom cards;
- graphic materials;
- format adaptations;
- visual products for which Canva offers a clear advantage.

Canva is complementary to NotebookLM rather than the default multimedia engine.

## Multimedia production pipeline

**Pedagogical diagnosis -> Level Control -> lesson/unit design -> assessment/evidence alignment -> QC-approved pedagogical source -> NotebookLM or appropriate specialized tool -> multimedia QC -> classroom-ready package**

When multiple formats are produced from one lesson, they should derive from the same approved pedagogical source so that slides, audio, video, worksheets, and assessment remain aligned.

## Multimedia Quality Control

A multimedia resource is not classroom-ready merely because it is visually attractive or technically complete. QC must verify:

- level appropriacy;
- language accuracy;
- fidelity to the approved source;
- alignment with the learning objective;
- communicative usefulness;
- appropriate information load;
- clarity of instructions;
- classroom usability;
- absence of unnecessary or unapproved content.

## Local models

Local language models may serve as offline or emergency resources. They remain subject to the same quality-control requirements as cloud-based tools.

## Coordination rule

**Pedagogical decision -> approved source content -> specialized production -> multimedia QC -> classroom use -> classroom evidence**

No secondary tool is considered the pedagogical authority merely because it produces a more attractive, longer, or faster output.
