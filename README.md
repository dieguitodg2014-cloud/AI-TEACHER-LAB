# AI TEACHER LAB

AI TEACHER LAB is a pedagogical and AI-assisted system for designing, reviewing, improving, and organizing classroom-ready ESL/EFL instruction.

## System principle

AI TEACHER LAB is not a repository of random activities. It is a coherent pedagogical system. Every product must be aligned with learning outcomes, learner level, communicative purpose, assessment evidence, and practical classroom constraints.

## Core architecture

- `01-MASTER-SYSTEM/` - system identity, pedagogical direction, framework, quality control, and AI tool coordination.
- `02-LEVEL-CONTROL/` - level adaptation from A0 through B2.
- `03-ESL-ENGINE/` - lesson design and MODO ESL rules.
- `04-ASSESSMENT/` - assessment design and alignment.
- `05-PROJECTS/` - specific teaching projects and programs.
- `06-RESOURCES/` - reusable supporting resources.

## Governing sequence

**Learning purpose -> level control -> lesson/course design -> communicative practice -> evidence of learning -> quality control -> final classroom-ready product**

## Quality principle

No material is considered finished merely because it is grammatically correct or visually attractive. It must also be pedagogically valid, level-appropriate, communicative, feasible, usable, and aligned with its intended learning outcome.
