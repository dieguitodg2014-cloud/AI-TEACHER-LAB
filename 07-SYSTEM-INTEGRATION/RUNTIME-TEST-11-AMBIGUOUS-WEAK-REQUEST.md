# RUNTIME TEST 11 - AMBIGUOUS OR WEAK REQUEST

## Purpose

Validate that the Director Pedagógico does not blindly execute a pedagogically weak request. The system must diagnose the request, preserve the valid instructional intent, identify the conflict, and redesign the lesson when possible.

## Test Input

`Hazme una clase B1 de Present Perfect de 90 minutos con 40 ejercicios de completar espacios y al final una conversación.`

## Diagnostic Analysis

### Valid intent

The request contains a clear and valid core intention:

- target level: B1
- target language: Present Perfect
- duration: 90 minutes
- desired oral production: a conversation

### Pedagogical conflict

The request specifies 40 gap-fill exercises as the dominant structure of the lesson. For B1, this is insufficient as the principal learning experience because the defined B1 requirements prioritize sustained communication, connected discourse, explanation/narration, interaction, reduced scripting, follow-up questions, fluency, and purposeful use of language.

Forty mechanical items would also create a serious time-allocation problem. If each item received even a small amount of student processing, checking, and feedback time, the lesson would leave inadequate time for meaningful B1 communication.

### Decision

**Do not execute the request literally.**

Preserve the requested topic, level, duration, and final conversation, but redesign the distribution of practice so that controlled form work supports rather than replaces communication.

## Corrected Pedagogical Design

### Learning result

By the end of the lesson, B1 learners will be able to discuss personal experiences and recent developments using the Present Perfect appropriately, distinguish relevant uses from Past Simple when necessary, and maintain a short interaction with follow-up questions.

### Evidence

Learners participate in a semi-open pair/group task in which they describe experiences or recent developments, ask follow-up questions, and respond to their partner's information. The final evidence is oral performance, not completion of grammar items alone.

### Revised 90-minute structure

| Stage | Time | Function |
|---|---:|---|
| Opening and context | 8 min | Establish a meaningful situation involving experiences/recent developments |
| Meaning and language focus | 12 min | Form, meaning, use, Present Perfect vs Past Simple where relevant |
| Controlled practice | 12 min | A focused set of gap-fill items, approximately 12-15, selected for diagnostic value |
| Guided practice | 15 min | Pair information-gap using prompts and follow-up questions |
| Conversation 1 | 8 min | Accessible model and noticing |
| Conversation 2 | 8 min | Extended model with follow-up questions and variation |
| Communicative task | 20 min | Semi-open discussion about experiences/recent developments |
| Feedback and exit evidence | 7 min | Delayed correction plus short individual/pair performance check |
| **Total** | **90 min** | |

## What Happened to the 40 Exercises?

The system does not simply ignore the teacher's desire for practice. It converts the valid purpose behind the request into more useful practice.

Instead of 40 gap-fill items:

- approximately 12-15 high-value controlled items are used;
- selected items target common form/use problems;
- the remaining time is transferred to guided and communicative practice;
- the original goal of practicing Present Perfect is preserved;
- the final conversation becomes evidence of actual communicative use.

If the teacher specifically needs all 40 items for homework, a separate worksheet can contain them without consuming the 90-minute class.
