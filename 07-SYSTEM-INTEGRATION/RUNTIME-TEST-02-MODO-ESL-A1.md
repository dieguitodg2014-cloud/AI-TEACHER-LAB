# AI TEACHER LAB - RUNTIME TEST 02

## Modo ESL A1

### Purpose

Validate that Modo ESL correctly activates A1 behavior and produces a functional lesson that moves beyond true-beginner support while remaining appropriate for basic learners.

## Test Input

`Modo ESL: there is / there are A1`

## Expected Behavior

1. Activate Modo ESL A1.
2. Use English for the explanation, as required above A0.
3. Target basic functional communication.
4. Increase independence compared with A0 without introducing unjustified complexity.
5. Include affirmative, negative, and question forms where pedagogically appropriate.
6. Move from controlled practice toward guided and communicative use.
7. Include two meaningful conversations.
8. Include a worksheet aligned with the taught language.
9. Maintain the default 90-minute Modo ESL architecture.
10. Keep assessment evidence aligned with the A1 communicative objective.

## Runtime Result

**PASS**

The system activated A1-specific behavior. The lesson used English for explanation and focused on describing locations and asking/giving basic information using there is / there are. It provided structured practice followed by supported interaction, with less scaffolding than an A0 lesson but without imposing B1-style cognitive or linguistic demands.

## A1 Compliance Checks

### Check 1 - Level Identification

**PASS** - A1 was treated as functional beginner communication rather than as A0 with more vocabulary.

**PASS** - The explanation was delivered in English, consistent with the Modo ESL rule for levels above A0.

**PASS** - Learners used the target structure for a practical communicative purpose: describing and locating things in places.

**PASS** - Language remained manageable and functional without unnecessary grammatical expansion.

### Check 5 - Scaffolding and Independence

**PASS** - Support was gradually reduced from modeling and controlled practice toward guided pair communication.

### Check 6 - Form and Meaning

**PASS** - Affirmative, negative, and question patterns were connected to meaning and use rather than practiced as isolated forms.

### Check 7 - Communicative Progression

**PASS** - The lesson progressed from controlled practice to guided interaction and supported freer production.

### Check 8 - Two Conversations

**PASS** - Two meaningful conversations were included as required by Modo ESL.

### Check 9 - Worksheet

**PASS** - The worksheet reinforced the target structure and communicative purpose without unnecessary new grammar.

### Check 10 - Timing

**PASS** - The default 90-minute Modo ESL duration was respected.

### Check 11 - Assessment Alignment

**PASS** - Final evidence required learners to use there is / there are to communicate basic information rather than simply recognize the forms.

## Validation Decision

**TEST 02 - PASS**

The runtime test confirms that Modo ESL can activate A1-specific behavior and increase learner independence and communicative demand appropriately without turning A1 into an overloaded higher-level lesson.
