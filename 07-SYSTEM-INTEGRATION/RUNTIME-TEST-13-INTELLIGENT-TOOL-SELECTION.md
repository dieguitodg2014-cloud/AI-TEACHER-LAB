# RUNTIME TEST 13 - INTELLIGENT TOOL SELECTION

**Version:** 1.0  
**Status:** PASS - Controlled runtime validation

## Purpose

Validate whether AI TEACHER LAB can decide what resources to create, reuse, adapt, or omit, and which production tool is appropriate, without the teacher prescribing the tool.

## Validation Principle

Pedagogical purpose is evaluated before technology. The system is rewarded for the smallest effective resource set, not maximum production.

## TEST 13-A - A0 Classroom Objects

**Learning need:** identify and say basic classroom objects and respond to simple teacher prompts.

**Required evidence:** learners identify objects and produce short oral responses.

**Resources justified:**
- CREATE: visual presentation/object image support.
- CREATE: simple audio/modeling support if learners need pronunciation/listening modeling.
- CREATE: short oral practice/teacher prompt cards if not already available.

**Resources omitted:** separate quiz; complex study guide; decorative video.

**Resources reused/adapted:** existing classroom-object images or teacher materials should be reused when accurate and level-appropriate.

**Recommended tool:** NotebookLM for source-based presentation/audio when available; no specialized tool for simple teacher prompt cards; Canva only if a specific visual-design need exists.

**Decision rationale:** A0 benefits strongly from concrete visual and auditory input. Tool choice follows the need rather than generating every possible medium.

**G13-G18:** PASS.

## TEST 13-B - A1 Daily Routines

**Learning need:** describe familiar daily routines using short connected utterances.

**Required evidence:** learners sequence and orally describe routine actions.

**Resources justified:**
- CREATE/ADAPT: visual routine sequence for modeling and speaking support.
- CREATE: compact speaking practice/worksheet if existing material is insufficient.

**Resources omitted:** full video production; separate recognition quiz unless assessment requires it.

**Resources reused:** existing routine visuals and previously approved lesson content where available.

**Recommended tool:** NotebookLM for presentation from approved lesson content; no specialized tool for simple worksheet/prompt material unless visual design requires Canva.

**Decision rationale:** sequencing and speaking support have clear value; additional multimedia does not automatically improve the learning outcome.

**G13-G18:** PASS.

## TEST 13-C - A2 Making Arrangements

**Learning need:** make suggestions, respond to suggestions, and reach agreement about a plan.

**Required evidence:** learners complete an authentic planning interaction using target language.

**Resources justified:**
- CREATE: presentation/input sequence.
- CREATE: role-play or information-gap cards.
- CREATE/ADAPT: concise worksheet for controlled and guided practice.

**Resources omitted:** standalone grammar quiz; video unless a specific model adds clear communicative value; redundant flashcards.

**Resources reused/adapted:** approved lesson source and existing arrangement scenarios should be reused/adapted.

**Recommended tool:** NotebookLM for the presentation; Canva for role-play cards only if visual layout materially improves usability; no specialized tool for ordinary worksheet text.

**Decision rationale:** the final evidence is communicative, so speaking resources have higher value than recognition testing.

**G13-G18:** PASS.

## TEST 13-D - B1 Present Perfect / Experiences

**Learning need:** sustain interaction about experiences, ask follow-up questions, and elaborate on personal experiences.

**Required evidence:** sustained pair/group interaction with follow-up questions and connected responses.

**Resources justified:**
- CREATE/ADAPT: presentation/input that establishes meaning and models interaction.
- CREATE: speaking framework with follow-up questions.
- CREATE: final speaking evidence/rubric support.
- CREATE/ADAPT: meaningful listening or authentic input only if it directly supports the communicative outcome.

**Resources omitted:** basic vocabulary flashcards; isolated grammar quiz; decorative video.

**Resources reused:** approved Present Perfect lesson content and existing experience prompts where suitable.

**Recommended tool:** NotebookLM for source-based presentation/audio when the approved source supports it; no specialized tool for speaking framework or rubric; another multimodal tool only if a specific authentic audio/video need is demonstrated.

**Decision rationale:** B1 requires sustained interaction and connected discourse, so production decisions prioritize interaction and meaningful input over recognition practice.

**G13-G18:** PASS.

## TEST 13-E - B2 Debate / Social Media and Society

**Learning need:** evaluate ideas, support positions, respond to opposing views, and use appropriate register and nuance.

**Required evidence:** structured debate/discussion demonstrating claims, reasons/evidence, responses to opposing views, and appropriate language.

**Resources justified:**
- CREATE/ADAPT: authentic or source-based input.
- CREATE: debate framework/evidence prompts.
- CREATE: assessment rubric aligned with B2 performance.
- CREATE/ADAPT: presentation or briefing material when it supports analysis and argumentation.

**Resources omitted:** basic vocabulary flashcards; elementary grammar worksheet; recognition quiz as the main assessment.

**Resources reused:** authentic sources and previously approved topic materials where valid and current.

**Recommended tool:** NotebookLM for source-based presentation/study materials when source fidelity is central; Canva for a specialized debate visual/framework only when design adds functional value; another multimodal tool only for a demonstrated media need; no specialized tool for the core debate rubric.

**Decision rationale:** B2 production must support evaluation, argumentation, nuance, and register. Technology is selected only when it improves those functions.

**G13-G18:** PASS.

## Cross-Level Validation

The five cases demonstrate that resource decisions change with proficiency and communicative purpose:

- A0: concrete visual/auditory scaffolding is high-value.
- A1: sequencing and structured speaking support are useful, with limited multimedia.
- A2: interaction resources become central; recognition testing is secondary.
- B1: sustained interaction and meaningful input become central.
- B2: authentic/source-based input, argumentation frameworks, evidence prompts, and performance assessment become central.

This confirms that resource selection is being driven by Level Control and communicative purpose rather than by a fixed multimedia package.

## Tool Selection Validation

The runtime demonstrates functional selection rather than automatic tool assignment:

- NotebookLM is preferred when source-based multimedia or study materials are pedagogically justified.
- Canva is complementary and reserved for specialized visual design where layout materially improves classroom use.
- Other multimodal tools are conditional, not default.
- Local Bionic is reserved for offline/emergency production rather than selected merely because it exists.
- No specialized tool remains a valid outcome.
