# AI TEACHER LAB - RUNTIME TEST 03

## Modo ESL A2

### Purpose

Validate that Modo ESL correctly activates A2 behavior and produces a lesson that moves learners toward routine independent communication and connected simple language, while remaining distinct from both A1 and B1.

## Test Input

`Modo ESL: Present Continuous for future arrangements A2`

## Expected Behavior

1. Activate Modo ESL A2.
2. Use English for the explanation.
3. Establish a functional communicative objective involving future arrangements.
4. Require more connected language and independence than A1.
5. Use controlled, guided, and freer practice in a meaningful context.
6. Include affirmative, negative, and question forms where appropriate.
7. Include two meaningful conversations.
8. Include a worksheet aligned with the taught language.
9. Maintain the default 90-minute Modo ESL duration.
10. Finish with communicative evidence appropriate to A2.

## Runtime Result

**PASS**

The system activated A2-specific behavior. The lesson used English for explanation and situated the Present Continuous in practical future arrangements such as plans, appointments, and scheduled activities. Learners moved from structured form practice toward connected exchanges and independent planning language, with reduced scaffolding compared with A1.
