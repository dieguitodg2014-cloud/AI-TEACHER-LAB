# RUNTIME TEST 14 - PILOT 06: PRODUCTION PIPELINE

**Version:** 1.0  
**Status:** CONTROLLED PIPELINE VALIDATION  
**Purpose:** Validate the transition from an approved pedagogical product to a coordinated, minimal, quality-controlled classroom-ready resource package.

## 1. Validation Objective

PILOT 06 validates this operational chain:

**Approved Lesson → Production Decision → Resource Plan → Specialized Tool Selection → Resource Production → Multimedia/Resource QC → Classroom-Ready Package**

The teacher requests a learning product, not a predetermined collection of files. The system must determine what resources are justified by the pedagogical purpose.

## 2. Pilot Case

**Course level:** A2  
**Lesson:** Making Arrangements - Lesson 1  
**Duration:** 90 minutes  
**Primary objective:** Students will make and respond to simple suggestions and reach an agreement about a plan.  
**Target language:**
- What do you want to do?
- I'd like to...
- How about...?
- Let's...
- That sounds good.
- I'm sorry, I can't.
- Maybe another day.

**Primary skill:** Speaking / interaction

## 3. Production Decision

The system evaluates each possible resource before production.

| Resource | Decision | Pedagogical reason |
|---|---|---|
| Presentation | CREATE | Supports input, noticing, modeling and task instructions. |
| Role-play cards | CREATE | Creates information variation and supports interaction. |
| Worksheet | CREATE | Provides controlled practice and a reusable record of learning. |
| Audio | CONDITIONAL | Create only if it materially improves listening/modeling; otherwise omit. |
| Video | OMIT | Not necessary for the stated objective and lesson evidence. |
| Quiz | OMIT | A quiz is not the best evidence for the communicative objective. |
| Speaking checklist/rubric | CREATE | Supports final oral evidence and feedback. |

The pilot therefore tests minimal effective production rather than maximum resource production.

## 4. Tool Coordination

The production system does not assume a tool before the resource need is identified.

- **NotebookLM:** preferred for source-based presentation, audio and study-material production when justified.
- **Canva:** complementary option for specialized visual design when visual design adds pedagogical value.
- **Gemini or another multimodal tool:** conditional use for a specific production requirement not better served elsewhere.
- **Bionic/local model:** offline or emergency support.
- **No specialized tool:** valid whenever the resource can be produced directly or is unnecessary.

All tools receive the same approved pedagogical source. Specialized tools cannot change the objective, level, target language, task, evidence or assessment criteria.

## 5. Production Requirements

Every authorized resource must preserve:

1. Target level: A2.
2. Lesson objective.
3. Target language.
4. Communicative purpose.
5. Interaction pattern.
6. Final evidence task.
7. Appropriate language load.
8. Classroom timing and usability.

No resource may introduce unnecessary grammar, vocabulary or cognitive demand.

## 6. Multimedia and Resource QC Gates

### G19 - Source Fidelity

The resource accurately represents the approved pedagogical source.

### G20 - Level Fidelity

The resource remains appropriate for A2 learners.

### G21 - Language Fidelity

Target language, examples, instructions and models are accurate and controlled.

### G22 - Pedagogical Function

The resource performs the function for which it was created.

### G23 - Classroom Usability

A teacher can use the resource without unnecessary preparation, repair or explanation.

### G24 - Multimodal Value

Multimedia elements improve comprehension, modeling, interaction or retention rather than merely decorating the product.

### G25 - Cross-Resource Consistency

Presentation, worksheet, role-play cards, assessment and any other authorized resources use consistent language, instructions, objectives and task logic.

## 7. Rejection Rules

A resource must be revised or rejected when:

- it is visually polished but pedagogically weak;
- it changes the intended level;
- it introduces unnecessary language;
- it duplicates another resource without adding value;
- it makes the teacher's job harder without improving learning;
- it contradicts the approved lesson;
- it supports a different objective;
- it creates activity overload;
- it consumes production effort without meaningful learning value.

## 8. Expected Output

The validated pipeline must produce a package containing only resources justified by the lesson:

- approved lesson;
- production decision record;
- presentation or equivalent input resource;
- role-play cards;
- controlled-practice worksheet;
- final speaking evidence/checklist;
- optional audio only if its pedagogical value is demonstrated;
- QC record.

## 9. Validation Result

PILOT 06 establishes the operational rule:

**The system does not ask, 'Which AI tool should I use?' first. It asks, 'What learning resource, if any, is pedagogically necessary?' first.**

The tool is selected only after the pedagogical production decision.

This pilot is considered successful when every authorized resource passes G19-G25 and the final package contains no unnecessary production.
