## QC Results

### G19 - Source Fidelity: PASS
The presentation preserves the approved communicative goal and the planned progression: real-life context, target expressions, controlled practice, Conversation 1, guided speaking, Conversation 2, Make a Plan, final speaking evidence, and exit check.

### G20 - Level Fidelity: PASS
The language and task design are appropriate for A2. The deck moves from supported input toward partner interaction and agreement-making. It does not turn the lesson into a higher-level grammar lesson.

### G21 - Language Fidelity: PASS WITH MINOR ACCEPTABLE EXTENSION
The core target language is correctly represented: "What do you want to do?", "I'd like to...", "How about...?", "Let's...", "That sounds good.", "I'm sorry, I can't.", and "Maybe another day." Additional natural A2 expressions such as "Great idea!", "Sure, let's do that!", and "What about Sunday then?" support the communicative function without changing the lesson objective.

### G22 - Pedagogical Function: PASS
The slide sequence maps to identifiable learning stages rather than functioning as decoration. Controlled, guided, freer, and final-evidence stages are explicitly represented. The final task directly asks learners to make a suggestion, respond, and reach agreement.

### G23 - Classroom Usability: PASS
The deck contains concise learner-facing instructions and two model conversations. The 15-slide structure is usable as classroom input/support rather than requiring the teacher to build the presentation from scratch.

### G24 - Multimodal Value: PASS - with visual-value monitoring
The presentation contains substantial visual media and uses a presentation format appropriate to classroom projection. Final QC principle remains that visuals must support meaning and interaction, not merely decoration. The available inspection confirmed the presence and placement of visual assets; semantic usefulness of every individual image is not fully machine-verifiable from metadata alone.

### G25 - Cross-Resource Consistency: PASS
The presentation is consistent with the approved Lesson 1 production plan: presentation CREATE, role-play cards CREATE, worksheet CREATE, audio CONDITIONAL, video OMIT, quiz OMIT, speaking checklist/rubric CREATE. No contradictory assessment or target language was detected.

## Language/Content Notes
1. "I'd like to" is correctly presented as a polite way to express a preference/intention.
2. "How about going to the cinema?" correctly uses a gerund after "How about".
3. "Let's" correctly uses the base verb.
4. The conversations model negotiation and agreement rather than isolated repetition.
5. The deck adds a few useful expressions beyond the minimum target set, but they remain functionally relevant and A2-appropriate.
