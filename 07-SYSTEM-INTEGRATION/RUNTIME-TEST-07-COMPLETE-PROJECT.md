# RUNTIME TEST 07 - COMPLETE PROJECT

## Purpose

Validate that AI TEACHER LAB can transform a multi-week ESL project request into a coherent learning system rather than a collection of disconnected lessons.

## Test Input

`Diseña un curso de inglés para adultos nivel A2 de 8 semanas, 3 clases por semana de 90 minutos, orientado a comunicación real. Incluye objetivos, unidades, evaluación, materiales y un proyecto final.`

## Expected System Behavior

The system should route the request through the Project Design Engine while coordinating Level Control, ESL Lesson Design, Assessment, Resource Management, AI Tool Coordination, and Quality Control.

The project should establish:

- learner profile and context;
- level-specific outcomes;
- overall communicative goals;
- measurable evidence;
- hierarchy of modules, units, lessons, activities, and evidence;
- sequencing and prerequisites;
- progression and spiral learning;
- assessment architecture;
- milestones and final deliverable;
- resource requirements;
- realistic time allocation;
- revision logic and QC.

## Controlled Runtime Design

### Project Parameters

- **Learners:** adults
- **Target level:** A2
- **Duration:** 8 weeks
- **Frequency:** 3 sessions per week
- **Session length:** 90 minutes
- **Total sessions:** 24
- **Total instructional time:** 36 hours
- **Primary purpose:** functional communication in familiar real-life situations

### Backward Design Result

The project begins with a final communicative result rather than with a list of grammar topics.

By the end of the course, learners should be able to participate in common everyday interactions, describe experiences and plans, ask for and provide information, handle routine problems, and complete a practical final communication task using connected but accessible language.

### Evidence

Evidence is distributed throughout the course rather than postponed until the final class.

Formative evidence includes short speaking tasks, information gaps, role plays, listening responses, short written messages, and unit performance checks.

Summative evidence includes a practical final project in which learners complete a realistic sequence of everyday communication tasks.

## Project Hierarchy

### Module 1 - Everyday Communication

Focus: introductions, routines, personal information, and basic interaction strategies.

### Module 2 - Getting Around and Making Arrangements

Focus: places, directions, schedules, invitations, and arrangements.

### Module 3 - Experiences and Stories

Focus: describing past events and experiences with increasing connectedness.

### Module 4 - Plans, Problems, and Solutions

Focus: future intentions, arrangements, routine problems, requests, and solutions.

Each module contains units, lessons, communicative activities, and evidence. Earlier language is recycled in later modules rather than treated as permanently completed.

## Level Control Validation

**PASS**

The project is designed for A2 learners. Expected output is connected but accessible language, moderate scaffolding, routine independent communication, and manageable information-gap and role-play tasks. The project does not impose B1-style sustained abstract argumentation as a core requirement.

## ESL Lesson Engine Integration

**PASS**

Individual 90-minute lessons are generated from module and unit outcomes. Lesson objectives must serve the project outcome. Activities progress from input and supported practice toward meaningful communication.

## Assessment Engine Integration

**PASS**

Assessment follows the chain:

**Learning Objective → Evidence → Task → Criteria → Feedback → Decision**

Unit evidence is used to identify areas needing review before learners progress. The final project measures functional communication rather than grammar recall alone.

## Resource Management Integration

**PASS**

Resources are selected according to lesson and project purposes. Required resources include teacher-ready dialogues, role-play prompts, information-gap materials, short texts/audio when appropriate, worksheets, and assessment tools. Resources are not allowed to introduce unnecessary language beyond the project objectives.

## AI Tool Coordination Integration

**PASS**

Specialized AI tools may transform approved lesson content into presentations, visuals, audio, or other formats. They may not change level, objectives, target language, communicative purpose, assessment evidence, or sequencing without pedagogical review.

## Quality Control Gates

### G1 - Level

**PASS** - A2 demands remain functional, connected, and appropriately scaffolded.

### G2 - Alignment

**PASS** - modules, units, lessons, activities, and assessments connect to the overall communicative outcomes.

### G3 - Language

**PASS** - target language is selected according to communicative need rather than grammar accumulation.

### G4 - Communication

**PASS** - each major stage contains purposeful interaction and meaningful learner output.

### G5 - Feasibility

**PASS** - 24 sessions x 90 minutes = 36 instructional hours. The hierarchy and progression are feasible within the stated duration when individual lessons are planned and audited separately.

## Integration Findings

The project request successfully activates multiple engines without allowing any single specialized component to replace the overall pedagogical design.

The information flow is coherent:

**Project Request → Diagnosis → A2 Level Control → Project Outcomes → Module/Unit Sequence → Lesson Design → Assessment/Evidence → Resources → Specialized Production → QC → Classroom Evidence → Revision**

The project is therefore treated as one connected learning system.

## Final Result

**STATUS: PASS**

The controlled runtime test demonstrates that AI TEACHER LAB can orchestrate a complete multi-week ESL project while preserving level control, communicative purpose, assessment alignment, resource governance, feasibility, and Quality Control.
